# Bizbooker
A booking website which uses reactjs as frontend and spring boot as backend

Full tech stack:
Frontend:React.js
Backend:Spring Boot,JPA,Hibernate,Stripe API,Gemini API,OpenStreetFreeMap API
Database:MySQL
Devops:Docker,Github Actions
Deployment:Microsoft Azure


Description:

This is a booking platform where different types of business providers can register their businesses and add multiple locations(if avaiable) for their businesses.Users can check businesses and view avaiable slots in a certain time frame and book slots according to their needs. There is a map for viewing all the business locations also there is a rating and review system so that users can see reviews and ratings to understand if the business is any good.Stripe API hase been integrated to the system to handle the payments for the bookings.A Chatbot has been built that can handle system specific queries and respond to users based on that
